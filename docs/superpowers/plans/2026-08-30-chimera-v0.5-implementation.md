# Chimera v0.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a standards-valid HTTP/3 CONNECT transport, uniform bounded decoy behavior, secure independent QUIC authentication, correct core/mihomo transport selection, and reproducible synchronized releases.

**Architecture:** Core hides HTTP/3, authentication, certificate, decoy, limiter, and tunnel behavior behind `quicx.ServerConfig`, `quicx.ClientConfig`, `ListenServer`, and `Client.DialTCP`. Mihomo implements the same v0.5 wire contract locally and selects TCP/QUIC before dialing. Both release pipelines build from clean tagged checkouts and verify embedded VCS metadata.

**Tech Stack:** Go 1.25.13+, quic-go/http3 v0.49.1 in core, MetaCubeX quic-go/http3 in mihomo, GitHub Actions, Debian 12 systemd installer.

**Spec:** `docs/superpowers/specs/2026-08-30-chimera-v0.5-h3-transport-design.md`

## Global Constraints

- QUIC protocol revision v0.5 is intentionally incompatible with v0.3/v0.4 raw QUIC.
- TCP/REALITY behavior remains compatible.
- QUIC requires an independent 32-byte `QUIC_PSK` and mandatory certificate pinning.
- Missing/invalid/replayed authentication uses the same bounded decoy response path as ordinary unauthenticated H3 traffic.
- No request-triggered decoy origin fetch is allowed.
- No documentation may claim REALITY-equivalent camouflage, guaranteed anti-censorship, anonymity, or unobservable traffic.
- No new third-party Go dependency is introduced.

    if err != nil { t.Fatal(err) }
    return &tls.Config{

        ServerName: "proxy.example",
        NextProtos: []string{http3.NextProtoH3},
        VerifyPeerCertificate: func(rawCerts [][]byte, _ [][]*x509.Certificate) error {
            if len(rawCerts) != 1 { return errors.New("unexpected certificate chain") }

func sendRawQUICStream(address string, tlsConfig *tls.Config, payload []byte) error {

    defer cancel()
    conn, err := quic.DialAddr(ctx, address, tlsConfig, &quic.Config{HandshakeIdleTimeout: time.Second})
    if err != nil { return err }
    defer conn.CloseWithError(0, "")
    stream, err := conn.OpenStreamSync(ctx)
    if err != nil { return err }
    if _, err := stream.Write(payload); err != nil { return err }
    _ = stream.SetReadDeadline(time.Now().Add(200 * time.Millisecond))
    var one [1]byte
    _, err = stream.Read(one[:])
    return err
}

    authority := r.Host
    if r.Method != http.MethodConnect || !s.auth.Validate(r.Header.Get("Authorization"), r.Method, authority, s.serverName, s.now()) {
